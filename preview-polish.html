API itu pelayan restoran. Kamu (aplikasi) pesan lewat menu (endpoint), dapur (server) masak, pelayan antar hasilnya.

Contoh paling simpel pakai fetch:

javascript · contoh-fetch.js
const res = await fetch("https://api.contoh.id/users");
const data = await res.json();
console.log(data);

Tiga hal yang wajib dicek: method, URL, dan API key.
